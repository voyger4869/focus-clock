# 踩坑记录

本文档汇总开发过程中遇到的技术难点与解决方案，避免重复踩坑。

## 一、安卓端 UI / 渲染

### 1. 按钮橙色高亮（Unicode 符号被渲染成 emoji）

- **现象**：控制按钮（▶⏹⏭⟲）在安卓 WebView 里显示为橙色圆角方块，`color` 属性失效。
- **根因**：这些 Unicode 字符被渲染成**彩色 emoji**，emoji 忽略 CSS 的 `color` 属性。
- **解决**：控制按钮全部改用**内联 SVG 图标**（`fill="currentColor"`）。其余装饰性 emoji（✕☀⏱）加 `&#xFE0E;` 文本变体选择符，body 加 `font-variant-emoji:text`。

### 2. 日历网格溢出（aspect-ratio 撑宽列）

- **现象**：手机端日历第 7 列（周日）溢出卡片，数字被裁切。
- **根因**：`.cal-cell` 用 `aspect-ratio:1`，窄屏上强制格子宽度跟随高度。
- **解决**：移除 `aspect-ratio`，改 `min-width:0`，配合 grid `repeat(7,1fr)` 均分。

### 3. 安卓端顶部裁切

- **现象**：内容延伸到状态栏后被裁切。
- **根因**：`LAYOUT_FULLSCREEN` 让内容进入状态栏区域但未适配。
- **解决**：改用 `setStatusBarColor` + `setNavigationBarColor` 同色方案，去掉 `LAYOUT_FULLSCREEN`。

### 4. 图标显示为右上角局部放大

- **根因**：生成 mipmap 图标时 wrapper 用 `object-fit:cover` + `100vw/100vh`，把图标放大裁切只留右上角。
- **解决**：每个尺寸独立 `<img width="N" height="N">` 固定尺寸等比缩放。

### 5. 安卓 WebView 不支持 blob 下载

- **现象**：导出功能（`URL.createObjectURL` + `<a download>`）在安卓端点击无反应。
- **根因**：Android WebView 默认不处理 blob URL 下载。
- **解决**：MainActivity 加 `JavascriptInterface`（`AndroidBridge.saveFile`），JS 端检测到桥存在则走桥保存到 Download 目录；同时加 `onShowFileChooser` 支持导入文件选择。

## 二、JS / 前端

### 6. 弹窗元素位置错误导致 getElementById 返回 null

- **现象**：`addEventListener` 报错、脚本中断。
- **根因**：需要 JS 绑定的元素 HTML 放在 `</script>` 之后。
- **解决**：**所有需要 JS 绑定的元素 HTML 必须放在 `<script>` 之前**。

### 7. 柱状图数值标签溢出

- **现象**：柱子顶到顶时数值标签被裁到 viewBox 外。
- **解决**：给 SVG 顶部留出 padding（`padT` 8→22，`H` 140→168）。

### 8. 壁纸导致界面发虚

- **现象**：整体界面模糊发虚。
- **根因**：壁纸层用 `color-mix` + `blur(20px)` 毛玻璃，副作用大。
- **解决**：彻底移除壁纸功能。

### 9. 倒数日日期偏移

- **现象**：倒数日天数不对（差一天）。
- **根因**：`new Date('YYYY-MM-DD')` 按 UTC 解析导致时区偏移。
- **解决**：`date.split('-').map(Number)` 用本地时区 `new Date(y, m-1, d)`。

## 三、同步机制

### 10. 删除后同步「复活」

- **现象**：设备 A 删除记录，同步后设备 B 的记录又回来了。
- **根因**：同步是 grow-only 并集合并，删除只在单设备生效。
- **解决**：引入**墓碑机制**——`state.deleted` 记录 `{type,id,ts}`，删除时 `addTombstone()`，同步时先并集合并墓碑，再按墓碑过滤已删除项。SYNC_VERSION 1→2。

## 四、打包 / 环境

### 11. ELECTRON_RUN_AS_NODE 导致 require('electron') 失败

- **现象**：`electron .` 时 `require('electron')` 返回字符串而非 API 对象。
- **解决**：打包/启动必须 `env -u ELECTRON_RUN_AS_NODE`。

### 12. winCodeSign 解压 symlink 失败

- **现象**：electron-builder 打包 nsis/portable 时中断（exit code 2）。
- **根因**：Windows 用户无 `SeCreateSymbolicLinkPrivilege`，winCodeSign 里 darwin 目录的符号链接创建失败。
- **解决**：手动预解压 winCodeSign 到缓存目录 `~/AppData/Local/electron-builder/Cache/winCodeSign/winCodeSign-2.6.0/`，把 `libcrypto.1.0.0.dylib` 复制为 `libcrypto.dylib`、`libssl.1.0.0.dylib` 复制为 `libssl.dylib` 补齐，app-builder 检测到目录已存在即跳过解压。

### 13. 默认 Java 是 IBM J9 JVM

- **现象**：Gradle 8.5 报 `JVMJ9TI064E`、instrumentation agent 加载失败。
- **根因**：本机默认 `java` 是 IBM SPSS 自带的 J9 JVM（Java 8），不兼容 Gradle。
- **解决**：打包时显式 `JAVA_HOME="/c/Program Files/Eclipse Adoptium/jdk-17.0.21.9-hotspot"`。

### 14. 路径含中文导致 AGP 报错

- **解决**：`gradle.properties` 加 `android.overridePathCheck=true`。

### 15. electron-builder 缺 main.js 报错

- **解决**：`package.json` 的 `build.files` 字段必须包含 `main.js`。

## 五、其他

### 16. 函数声明提升导致的无限递归（历史教训）

- 注意 `save()` 内部广播与全局引用的关系，避免 `_origSave = save` 类自引用导致的递归。

### 17. Android WebView 后台计时冻结

- **现象**：安卓端退后台/锁屏后，番茄钟计时冻结（时间不走）。
- **根因**：计时靠 JS `setInterval` 每秒 `state.remaining--`，Android 会在应用后台/锁屏时挂起 WebView 的 JS 线程，定时器停止执行。
- **解决（两层）**：
  1. **JS 层**：计时改为**绝对时间戳基准**——开始时记 `endAt = Date.now() + remaining*1000`，`tick()` 用 `endAt - Date.now()` 实时算剩余（而非递减）。这样即使 JS 被挂起，恢复前台时 `visibilitychange`/`pageshow` 立即 `tick()` 追平真实时间。
  2. **原生层**：新增 `TimerService` 前台服务保活 + 到点发系统通知。JS 通过 `AndroidBridge.timer(action, payload)` 桥把 start/pause/cancel 传给原生，原生用 `Handler` 精确计时，到点发 Notification。

### 18. Android 13+ 通知权限与前台服务类型

- **现象**：targetSdk 34 下发通知需要动态申请 `POST_NOTIFICATIONS`，前台服务必须声明 `foregroundServiceType`。
- **解决**：
  - `MainActivity` 在 `onCreate` 里 Android 13+ 自动 `requestPermissions(POST_NOTIFICATIONS)`。
  - Manifest 加 `POST_NOTIFICATIONS`、`FOREGROUND_SERVICE`、`FOREGROUND_SERVICE_DATA_SYNC`、`VIBRATE` 权限。
  - `<service android:foregroundServiceType="dataSync">`（计时类用 dataSync 语义可接受；`specialUse` 需额外 property 声明，未采用）。

### 19. 前台服务 startForeground 5 秒限制

- `TimerService.onStartCommand` 处理 `start` 时必须**立即**调用 `startForeground()`（Android 8+ 要求 5 秒内），否则崩溃 `ForegroundServiceDidNotStartInTimeException`。本实现中 `handleAction→start()` 首行即 `startForeground`。

### 20. Web Audio 在后台/锁屏无声

- **现象**：后台/锁屏时专注结束，通知正常但**没有提示音**。
- **根因**：`playAlertSound` 用 Web Audio API（`AudioContext` + `OscillatorNode`），Android 挂起 WebView 的 JS 线程后 AudioContext 停止，且 WebView 在 `file://` 下后台音频也会被暂停。
- **解决**：结束提示音改由**原生层** `TimerService` 用 `ToneGenerator`（`AudioManager.STREAM_NOTIFICATION`）播放三连音。注意：
  - `ToneGenerator` 用 `handler.postDelayed` 分时播放，避免在主线程 `Thread.sleep`。
  - 服务 `stopSelf()` 要**延迟**（约 1.2s）到提示音播完，否则服务立即销毁导致 Handler 回调不执行。
  - 通知自带 `DEFAULT_SOUND` 也会响，`ToneGenerator` 是额外的、更明确的提示音。

### 21. 计时结束闪退 + 后台无记录（v1.5.2 修复）

- **现象**：计时结束瞬间 App 闪退，且结束后的专注记录丢失；后台/锁屏结束时同样无记录并闪退。
- **根因（两层）**：
  1. **闪退**：`MainActivity.JsBridge.timer()` 对所有 action（`start`/`pause`/`cancel`）都调用 `startForegroundService()`。而 `pause`/`cancel` 的 handler 会立即 `stopForeground()`/`stopSelf()`，**根本没有调用 `startForeground()`**，违反 Android 8+ 的「`startForegroundService` 启动后 5 秒内必须 `startForeground`」约束，系统抛 `ForegroundServiceDidNotStartInTimeException` → App 直接闪退。计时结束时 JS 恰好会 `notifyNativeTimer('cancel')`，于是必然崩溃。
  2. **无记录**：后台/锁屏时 WebView 的 JS 线程被挂起，`setInterval` 不执行，`completeSession` 不会触发；原生前台服务到点后只发通知，**不负责记录 session**，导致这条专注永久丢失。
- **解决**：
  1. **区分启动方式**：仅 `start` 走 `startForegroundService`（且 `start()` 首行即 `startForeground`），`pause`/`cancel` 改用普通 `startService`，配合服务端 `stopping` 幂等标志避免重复 `stopForeground`。
  2. **后台补记机制**：`start` 时 JS 把 `{mode, startedAt, total, taskId, taskName}` 传给原生；原生 `TimerService` 到点后把完成事件写入 `SharedPreferences`（保留最近 50 条）；新增桥方法 `AndroidBridge.consumeCompletions()` 取回并清空队列。JS 端在 `init()`、`visibilitychange`、`pageshow` 时调用 `consumeNativeCompletions()` 补记 session（带 startedAt+durationSec 去重），彻底解决后台丢记录。

### 22. 通知栏内联按钮 → JS 指令回传（v1.6.0）

- **需求**：通知栏加「暂停/跳过」按钮，点击后要让 WebView 里的 JS 执行对应动作（计时状态由 JS 维护）。
- **难点**：通知按钮的 `PendingIntent` 只能回到 Service/Activity，无法直接调 JS；且 App 可能在前台或后台。
- **解决（双通道）**：
  1. 通知按钮 → `PendingIntent.getService(..., action="pause"/"skip"/"startNext")` → `TimerService.onStartCommand` 收到后：
     - 把指令写入 `SharedPreferences`（`pending_cmd`），供 App 不在前台时下次打开读取；
     - 发**包内广播** `ACTION_CMD`（`sendBroadcast` + `setPackage`）。
  2. `MainActivity` 注册 `BroadcastReceiver`（Android 13+ 用 `registerReceiver(receiver, filter, RECEIVER_EXPORTED)`，低版本用两参重载），收到广播立即 `webView.evaluateJavascript("window.__nativeCmd('"+cmd+"')")`。
  3. JS 端 `window.__nativeCmd(cmd)` 分发到 `pauseTimer()`/`discardTimer()`/`startTimer()`；`consumeNativeCommand()` 在 `init`/`visibilitychange`/`pageshow` 时通过 `AndroidBridge.consumeCommand()` 读取并执行遗留指令。
- **踩坑**：Android 13+ 注册广播接收器**必须**带 `RECEIVER_EXPORTED`/`RECEIVER_NOT_EXPORTED` flag，否则抛 `ReceiverCallNotAllowedException`；`Notification.Builder.addAction` 的图标用系统内置 `android.R.drawable.ic_media_pause` 等，避免缺图标资源。

### 23. Electron 托盘 + 最小化 + preload 通知（v1.6.0）

- **需求**：Windows 版最小化到托盘、结束弹系统通知。
- **方案**：
  - `main.js` 用 `Tray`（`icon-192.png`，点击恢复窗口，右键菜单「显示/退出」）。
  - 关闭窗口拦截：`win.on('close')` 里 `isQuitting` 为假时 `preventDefault()` + `hide()`，托盘退出时才真正 `app.quit()`。
  - 通知走 IPC：`preload.js` 用 `contextBridge.exposeInMainWorld('electronAPI', {notify})`，`main.js` 里 `ipcMain.on('notify')` 弹 `new Notification()`；渲染进程调用 `window.electronAPI.notify(title, body)`。
- **踩坑**：`contextIsolation:true` 下渲染进程拿不到 `require('electron')`，必须用 preload + `contextBridge` 暴露；`window-all-closed` 事件不能直接 `app.quit()`（否则关闭窗口就退出了，托盘失效）。
