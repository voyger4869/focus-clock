# 开发方向

本文档规划项目未来的发展方向与路线图，作为后续迭代的参考。

## 产品理念

番茄钟/专注类应用的核心留存逻辑是「**习惯养成 + 成就感反馈 + 数据看得见**」。当前产品已做到"数据看得见"，下一步重点转向"习惯养成"和"成就感反馈"。

## 已规划方向

### 1. 习惯养成机制（未做，优先级高）

- **每日目标系统**：设置每日专注目标（如 2 小时），达标解锁打卡/徽章，主界面显示今日进度环。
- **成就徽章**：里程碑式激励，如：
  - 首个番茄 / 连续 7 天 / 连续 30 天
  - 累计 10 小时 / 50 小时 / 100 小时
  - 单日 4 小时 / 单周 20 小时
- **连续打卡强化**：与现有 streak 结合，展示连续专注的最佳纪录。

### 2. 专注报告（数据看板的延伸）

- **周报 / 月报摘要**：每周一自动生成「本周专注 X 小时、比上周多 Y、最专注任务 Z」。
- **最佳专注时段**：已有黄金时段提示，可扩展为「你下午 3 点效率最高」类洞察。
- **周维度对比扩展**：本周 vs 上周已有，可扩展为 12 周滚动趋势。

### 3. 使用体验打磨

- **专注环境音**（可选）：雨声、咖啡馆等环境音，做成可选开关。注意吸取壁纸 bug 教训（毛玻璃/color-mix 导致发虚），不引入高风险渲染。
- **更多主题**：现有 8 套，可增加浅色主题（当前全为深色）。
- **番茄周期可视化增强**：时间轴已支持单日，可加「周视图」。

### 4. 数据与备份

- **自动备份提醒**：定期提醒导出备份。
- **云端同步（可选）**：当前仅局域网同步，若用户需要跨网络同步，可考虑可选的自建服务（需用户明确同意，默认保持本地优先）。

### 5. 工程质量

- **代码拆分**：当前 `index.html` 约 2700 行单文件，功能增多后可考虑拆分模块（但需保留零构建的便利性，权衡后决定）。
- **测试**：补充核心逻辑的自动化测试（合并逻辑、墓碑机制、计时状态机）。

## 优先级建议

| 优先级 | 方向 | 理由 |
|--------|------|------|
| ⭐⭐⭐ | 目标系统 + 成就徽章 | 留存核心，纯前端，收益大 |
| ⭐⭐⭐ | 周报/月报摘要 | 成就感反馈，复用现有数据 |
| ⭐⭐ | 专注环境音（可选） | 体验提升，需谨慎实现 |
| ⭐⭐ | 周维度对比扩展 | 数据更专业 |
| ⭐ | 浅色主题 | 视觉多样性 |
| ⭐ | 代码拆分/测试 | 工程质量，长期价值 |

## 决策记录（历史）

- ✅ 砍掉「线上自习室」「悬浮时钟/小组件」——聚焦核心。
- ✅ 移除白噪音/翻页音效/壁纸——壁纸导致界面发虚，白噪音/翻页音效非必需。
- ✅ 采用零依赖单文件方案——避免构建复杂度，易于三端复用。
- ✅ 同步用 WebRTC 手动配对码——零服务器、隐私优先。

> 注：本文档是规划参考，实际开发顺序以用户最新决定为准。
