## 开发历程（按轮次）

### 第一轮：项目立项与基础功能

- 逆向调研「翻页时钟」App（base.apk，360 加固，核心 Java 无法提取，仅参考 UI/资源）。
- 确立差异化：多设备同步 + PC 端。
- 用户决策：砍掉「线上自习室」「悬浮时钟/小组件」，其余整合。
- 实现单文件 `index.html`（零依赖），含翻页音效、指针表盘、正计时、倒数日、打卡、白噪音、壁纸、沉浸模式。

### 第二轮：修 bug + 仪表盘视觉优化

- 修复弹窗窗口溢出（`.modal` 加 max-height + overflow）。
- 设置面板紧凑化。
- 仪表盘对齐「翻页时钟」质感：指标卡加图标、周对比双柱、热力图改 GitHub 风格。

### 第三轮：修复沉浸退出 bug + 日历视图

- **严重 bug**：沉浸模式无退出出口 → 加浮动退出按钮 + Esc。
- 新增日历记录视图（月历 + 点击看明细）。
- 踩坑：JS 绑定的元素 HTML 必须放 `<script>` 之前。

### 第四轮：精简 + 计时控制 + 局域网同步 + 打包

- 精简：移除白噪音、翻页音效、壁纸（壁纸是界面发虚的根源）。
- 计时控制拆分：提前结束（记录）/ 跳过（不记录）。
- **核心：局域网 P2P 同步**（WebRTC + 手动配对码，数据按 id 并集合并）。
- 打包：PWA + Electron（NSIS + portable）。

### 第五轮：安卓原生 APK 打包

- 搭建环境：JDK 17 + Android SDK + Gradle 8.5。
- 极简 WebView 壳方案（不用 Capacitor）。
- 产物：`专注时钟-安卓-v1.0.0.apk`。

### 第六轮：安卓 bug 修复 + 删除同步墓碑

### 第十一轮：统计看板布局自定义（v1.4.0）

- 统计看板各板块支持**显示/隐藏 + 拖动排序**（设置里新增「统计看板布局」管理区）。
- 排序方式：桌面端 HTML5 拖拽手柄；触屏端上移/下移按钮兜底（Android WebView 不支持拖拽）。
- 布局配置存 `state.settings.statsLayout`（order + hidden + ts 时间戳），**纳入局域网同步**（时间戳较新优先合并）。
- 产物：v1.4.0。

### 第十二轮：后台计时 + 结束通知（v1.5.0）

- **修复后台计时冻结**：Android WebView 退后台/锁屏后 JS 定时器被挂起，计时冻结。改为**基于绝对时间戳 `endAt`** 计算剩余，恢复时自动追平。
- **前台服务保活**：新增 `TimerService`（前台服务），JS 通过 `AndroidBridge.timer()` 桥通知原生层 start/pause/cancel，后台维持计时。
- **结束通知**：专注/休息到点发系统通知（含「专注完成 🎉」文案 + 任务名），点通知回到 App 自动补记 session。
- Android 13+ 自动申请 `POST_NOTIFICATIONS` 权限；新增前台服务、震动权限。
- 产物：v1.5.0。

### 第十三轮：后台结束提示音 + 时钟装扮优化（v1.5.1）

- **修复后台无提示音**：原 `playAlertSound` 用 Web Audio，后台/锁屏时 AudioContext 挂起无声。改为 `TimerService` 到点用原生 `ToneGenerator` 播放三连提示音，`stopSelf` 延迟 1.2s 确保播完。
- **时钟装扮优化**：
  - 圆环：加内圈轨道细环 + 进度百分比文字（精致感）
  - 大数字：加模式标签（下方），纵向布局
  - 极简：从"小圆环"改成**纯大字号时间 + 模式标签**，与圆环区分开
  - 点击时钟数字聚焦时长调节扩展到极简大字
- 产物：v1.5.1。

### 第十四轮：修复计时结束闪退 + 后台丢记录（v1.5.2）

- **修复结束闪退**：`JsBridge.timer()` 对所有 action 都走 `startForegroundService`，而 `pause`/`cancel` 会立即 `stopForeground`/`stopSelf`、从未 `startForeground`，违反 Android 8+「5 秒内必须 `startForeground`」约束 → `ForegroundServiceDidNotStartInTimeException` 闪退。改为仅 `start` 用 `startForegroundService`，`pause`/`cancel` 用普通 `startService`，服务端加 `stopping` 幂等标志。
- **修复后台丢记录**：后台/锁屏时 JS 线程被挂起、`completeSession` 不触发，原生只发通知不记录，专注永久丢失。新增后台补记机制：`start` 时 JS 把 `{mode, startedAt, total, taskId, taskName}` 传原生；原生到点把完成事件写入 `SharedPreferences`；JS 在 `init`/`visibilitychange`/`pageshow` 通过 `AndroidBridge.consumeCompletions()` 取回并补记（带去重）。
- 产物：v1.5.2。

### 第十五轮：体验优化包（v1.6.0）

一次性落地 7 项体验优化（用户指定，跳过专注报告）：

1. **通知栏内联控制 + 倒计时**：`TimerService` 持续通知实时显示剩余时间（每约 15s 更新），加「暂停」「跳过」按钮（`PendingIntent.getService` 发 action）；结束通知加「开始休息/专注」按钮。通知按钮指令经 `SharedPreferences` 暂存 + 广播 → `MainActivity` 注册 `BroadcastReceiver` → `webView.evaluateJavascript` 调 `window.__nativeCmd(cmd)`；App 不在前台时，指令留待 JS 恢复时通过 `AndroidBridge.consumeCommand()` 读取执行。
2. **自动衔接下一轮**：`settings.autoNext` 开关，自然结束后延迟 1.2s 自动 `startTimer()`（提前结束/跳过/正计时不触发）。
3. **每日目标**：`settings.dailyGoal`（分钟），计时视图目标进度条 `goalBar`，达成当日只弹一次庆祝提示。
4. **成就徽章**：12 个成就（`ACHIEVEMENTS` + `check` 函数），达成弹提示，统计页新增「成就徽章」看板（复用 `data-panel` 布局系统）。
5. **记录备注**：session 加 `note` 字段，历史记录显示 + `history-note-btn` 编辑（prompt）。
6. **多设备同步冲突提示**：`mergeById` 检测同 id 的 name 不一致 → `syncConflicts` → `flushSyncConflicts()` 弹 toast。
7. **白名单保活引导**：`MainActivity` 首次启动弹 `AlertDialog` 引导去电池优化/后台白名单设置，`REQUEST_IGNORE_BATTERY_OPTIMIZATIONS` 权限。
8. **PC 端托盘 + 通知**：`electron/main.js` 加 `Tray`（点击恢复、右键退出）、关闭最小化到托盘；`preload.js` 经 `contextBridge` 暴露 `electronAPI.notify`，JS `notifyDesktopCompletion()` 弹系统通知。

- 产物：v1.6.0。
