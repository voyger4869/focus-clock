# 项目说明

## 一句话定位

一款**番茄钟 + 翻页时钟**应用，主打「专注统计 + 多设备局域网同步」，安卓与 PC 双端可用，不依赖任何第三方服务器。

## 项目背景

- 灵感来源：调研了「翻页时钟」App（base.apk，杭州茶沐网络科技），其翻页钟 + 番茄钟 + 专注统计体验良好。
- 它的短板：**无多设备同步、无 PC 端**。
- 我们的差异化：补上「局域网 P2P 数据同步」与「PC 桌面端」这两个缺口，同时砍掉了「线上自习室」「悬浮时钟/小组件」等次要功能，聚焦核心体验。

## 核心特性

1. **番茄钟计时**：专注 / 短休息 / 长休息三种模式，长休息每 4 个番茄自动触发。
2. **多种时钟外观**：圆环进度、复古翻页、大数字切换、指针表盘、极简，共 5 种。
3. **专注任务标注**：每次专注可标注任务，支持任务的新建、删除、重命名（按 id 关联，历史数据不丢失）。
4. **丰富统计仪表盘**：今日/累计/连续天数/日均/单日最高指标卡，近 7 天柱状图、近 30 天趋势折线图、任务分布环形图、专注时段分布、本周时段、热力图、日历记录、番茄时间轴、周对比。
5. **局域网 P2P 同步**：WebRTC DataChannel + 手动配对码，纯局域网、无服务器、无第三方。
6. **每日打卡**：习惯养成，近 7 天打卡格 + 连续天数统计。
7. **倒数日 / 纪念日**：重要日期倒计时。
8. **数据备份**：导出 JSON 全量备份 / CSV（Excel 可开），导入合并恢复。
9. **个性化**：8 套主题配色 + 12 预设强调色 + 自定义取色器。
10. **沉浸专注模式**：全屏防干扰，浮动退出按钮 + Esc 退出。

## 技术架构

- **前端**：单个 `index.html` 文件，原生 HTML/CSS/JS，**零第三方依赖**，无框架、无构建步骤。
- **数据持久化**：`localStorage`，所有数据存本机。
- **音频**：Web Audio API 合成提示音（无音频文件）。
- **同步**：WebRTC DataChannel + 手动配对码（base64 承载 SDP），数据按 id 并集合并（grow-only）+ 墓碑机制保证删除同步。
- **跨平台**：
  - 网页版 / PWA：浏览器直接打开，可「添加到主屏幕」。
  - 安卓版：原生 WebView 壳（`android.app.Activity` + WebView，无 Capacitor 依赖）。
  - Windows 版：Electron 打包（NSIS 安装包 + portable 便携版）。

## 数据模型

核心数据存于 `localStorage`：

| Key | 内容 |
|-----|------|
| `tasks` | 任务列表 `{id, name, color}` |
| `sessions` | 专注记录 `{id, taskId, startedAt, durationSec, mode, skipped}` |
| `habits` | 打卡习惯 `{id, name, days[]}` |
| `countdowns` | 倒数日 `{id, name, date}` |
| `deleted` | 删除墓碑 `{type, id, ts}`（用于跨设备同步删除） |
| `settings` | 设置（主题、时长、音效、强调色等） |
| `currentTask` | 当前选中任务 id |

## 设计原则

- **零依赖**：单文件，不联网即可完整使用（同步仅在局域网内点对点）。
- **数据不丢失**：多设备同步按 id 并集合并，删除用墓碑机制，绝不丢失、绝不复活。
- **隐私优先**：所有数据本地存储，同步不经任何第三方服务器。
