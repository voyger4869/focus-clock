## 快速开始

- **直接体验网页版**：用浏览器打开项目根目录的 `index.html`
- **安装安卓版**：安装 `releases/` 目录下最新的 `专注时钟-安卓-v*.apk`
- **安装 Windows 版**：安装 `releases/` 目录下的 `专注时钟-Windows-Setup-*.exe`
- **修改代码**：核心逻辑都在根目录的 `index.html`（单文件，零依赖）

## 项目结构速览

```
focus-clock/
├── index.html                 # 核心应用（单文件，零依赖）
├── manifest.json / sw.js      # PWA 配置与离线缓存
├── icon.svg / icon-*.png      # 应用图标
├── doc/                       # 项目文档（本目录）
├── electron/                  # Electron 桌面版工程
│   ├── main.js                # 主进程（窗口/托盘/通知）
│   ├── preload.js             # 安全桥
│   └── package.json           # electron-builder 打包配置
├── android-app/               # 安卓原生 WebView 壳工程
│   ├── app/src/main/          # MainActivity.java + assets
│   └── keystore.properties.example  # 签名配置模板
└── releases/                  # 历史版本安装包（APK / EXE）
```
