# 开发环境

本文档记录本项目的开发环境、工具链、构建与打包方法。

## 环境概览

| 项 | 版本 / 位置 | 说明 |
|----|-------------|------|
| 操作系统 | Windows | 项目路径含中文「时钟」 |
| Node.js | 22（npm 10） | Electron 打包用 |
| JDK | 17（Eclipse Adoptium） | 安卓打包用，**关键**（见下） |
| Gradle | 8.5（本地） | 安卓打包用 |
| Android SDK | android-34 + build-tools 34.0.0 | 安卓打包用 |
| Electron | ^31 | 桌面端 |
| electron-builder | ^24.13 | 桌面端打包 |

## 关键路径

```
项目根目录        D:\wrokbuddy_project\时钟\
JDK 17           D:\wrokbuddy_project\时钟\jdk-17.0.2\
Gradle 8.5       D:\wrokbuddy_project\时钟\gradle-8.5\bin\gradle.bat
```

> ⚠️ 注意：本机默认 `java` 是 IBM SPSS 自带的 **J9 JVM**（Java 8），与 Gradle 8.5 不兼容，会报 `JVMJ9TI064E` 错误。打包必须显式指定 JDK 17。

## 核心开发流程

### 修改代码

核心逻辑全在根目录 **`index.html`**（单文件）。改完后需同步到三处：

```bash
# 同步到 Electron 和安卓 assets
cp index.html electron/index.html
cp index.html android-app/app/src/main/assets/index.html
```

### 语法校验

```bash
node -e "const h=require('fs').readFileSync('index.html','utf8');const m=h.match(/<script>([\s\S]*?)<\/script>/);new Function(m[1]);console.log('OK')"
```

## 打包安卓 APK

```bash
cd android-app
JAVA_HOME="/c/Program Files/Eclipse Adoptium/jdk-17.0.21.9-hotspot" \
  "/d/wrokbuddy_project/时钟/gradle-8.5/bin/gradle.bat" assembleRelease --no-daemon
# 产物：android-app/app/build/outputs/apk/release/app-release.apk
```

### 安卓打包要点

- 签名：`release.keystore`（alias `focusclock`，密码 `focusclock123`），已配在 `build.gradle`。
- `android.overridePathCheck=true`：绕开路径含中文「时钟」导致的 AGP 报错。
- 图标：`icon-512.png` 经 Chrome headless 生成 5 个密度 mipmap 图标。

## 打包 Windows（Electron）

```bash
cd electron
env -u ELECTRON_RUN_AS_NODE npm run dist
# 产物：electron/dist/专注时钟 Setup 1.0.0.exe（安装版）
#       electron/dist/专注时钟 1.0.0.exe（portable 便携版）
```

### Electron 打包要点

- 必须 `env -u ELECTRON_RUN_AS_NODE`（本机默认带此变量会导致 require('electron') 失败）。
- 镜像加速：`ELECTRON_MIRROR`、`ELECTRON_BUILDER_BINARIES_MIRROR`（见 [踩坑记录](./踩坑记录.md)）。
- winCodeSign 解压 symlink 失败需手动预置缓存目录。

## 环境搭建历史（首次搭建记录）

1. **JDK 17**：华为镜像下载 `openjdk-17.0.2_windows-x64_bin.zip` → 解压到 `jdk-17.0.2`。
2. **Android SDK**：`commandlinetools-win-11076708_latest.zip`，用 sdkmanager 装 `platform-tools` + `platforms;android-34` + `build-tools;34.0.0`。
3. **Gradle 8.5**：腾讯镜像 `mirrors.cloud.tencent.com/gradle/gradle-8.5-bin.zip` → 解压到 `gradle-8.5`。

## 验证方式

- **网页版**：Chrome 直接打开 `index.html`，或用 puppeteer-core headless 加载检测运行时错误。
- **安卓**：真机安装 APK 验证（当前无连接设备时，以 Chrome 模拟器 + 语法校验替代）。
- **Windows**：安装 `Setup 1.0.0.exe` 或运行 portable 版。
