# 功能清单

本文档详细列出已实现的全部功能，按模块分类。

## 1. 计时器（番茄钟）

- **三种模式**：专注、短休息、长休息，底部 pill 切换。
- **正计时 / 倒计时**：倒计时为主，另支持「正计时」模式（结束也记为专注）。
- **长休息自动触发**：每完成 4 个番茄，自动进入长休息。
- **时长可调**：设置里可调专注（5–90 分）、短休息（1–30 分）、长休息（5–45 分）。
- **前置时长调节（v1.3.0 新增）**：计时界面时钟下方直接显示时长调节面板——横向拖动滑块 + 加减按钮 + 快捷预设（如 15/25/30/45/60 分），无需进设置；**点击时钟数字**也会聚焦定位到调节面板。计时中自动禁用（本轮不变，下次生效）。
- **控制按钮**：
  - 开始 / 暂停（中央大按钮）
  - 重置（⟲）
  - 提前结束（⏹）：记录已专注时长，历史打「提前结束」标签
  - 跳过（⏭）：完全不记录、作废本轮
- **键盘快捷键**：空格 = 开始/暂停，Esc = 退出沉浸模式。
- **自动衔接下一轮（v1.6.0 新增）**：设置里开启后，专注/休息自然结束后自动开始下一模式（提前结束/跳过不自动衔接）。
- **每日目标（v1.6.0 新增）**：设置目标专注分钟数（0=不设），计时界面显示目标进度条，达成弹庆祝提示。

## 2. 时钟外观（5 种）

| 外观 | 说明 |
|------|------|
| 圆环进度 | 环形进度条 + 内圈轨道 + 进度百分比 + 数字 |
| 复古翻页 | 翻页钟效果 |
| 大数字切换 | 大字号数字切换动画 + 模式标签 |
| 指针表盘 | 模拟表盘，指针映射剩余时间 |
| 极简大字 | 纯大字号时间 + 模式标签（无圆环） |

## 3. 专注任务

- 每次专注可标注任务（顶部任务胶囊，点击弹出选择）。
- 任务支持**新建**（可选颜色）、**重命名**（按 id 更新，历史记录自动跟随）、**删除**（记录墓碑，跨设备同步删除，历史记录保留但不再归属该任务）。
- 默认 6 个内置任务：阅读、学习、工作、编程、健身、写作。

## 4. 统计仪表盘

- **指标卡**：今日专注、累计专注、完成番茄数、连续天数、日均专注、单日最高。
- **近 7 天柱状图**：每日专注时长，今日高亮。
- **近 30 天趋势折线图**：专注走势 + 今日高亮圆点。
- **专注时段分布环形图**：清晨/上午/下午/夜间四段 + 黄金专注时段提示。
- **任务分布环形图**：各任务专注时长占比。
- **本周专注时段柱状图**：按小时汇总。
- **专注热力图**：GitHub 风格，近 12 周 × 7 天。
- **今日番茄时间轴**：当天番茄按时间比例排布成块状。
- **日历记录**：月历网格，有数据的日期高亮，点击看当天明细。
- **本周 vs 上周对比**：双柱对比 + 环比涨跌。
- **看板布局自定义（v1.4.0 新增）**：设置里可对统计看板各板块**显示/隐藏 + 拖动排序**（桌面端拖拽手柄，触屏端上下移动按钮），布局配置跨设备同步。
- **成就徽章（v1.6.0 新增）**：12 个成就（首次番茄、累计 5/20/100 个、连续 3/7/30 天、单日 2h/5h、早起鸟、累计 10h/50h），达成自动弹提示，统计页勋章墙展示。

## 5. 局域网 P2P 同步

- 纯局域网点对点，无服务器、无 STUN/TURN、无第三方。
- 手动配对码（base64 承载 SDP offer/answer）+ 二维码。
- 配对成功后数据自动合并（按 id 并集，去重不丢失），之后实时自动同步。
- 删除通过墓碑机制同步，不会「删除后复活」。
- **冲突提示（v1.6.0 新增）**：同一数据在多台设备被改成不同内容时（如任务重命名），合并后弹提示并保留本机版本。

## 5.5 后台计时与通知（v1.5.0 新增）

- **后台计时不冻结**：计时改为基于绝对时间戳（`endAt`），退后台/锁屏后恢复时自动追平真实时间。
- **前台服务保活**：Android 原生 `TimerService` 前台服务维持计时，避免 WebView 被系统挂起。
- **结束通知**：专注/休息结束时发出系统通知（Android 13+ 自动申请通知权限），点通知回到 App 自动补记 session。
- **结束提示音（v1.5.1 增强）**：结束提示音改由原生层 `ToneGenerator` 播放，后台/锁屏时也能响（Web Audio 在后台会被挂起）。
- **通知栏内联控制 + 倒计时（v1.6.0 增强）**：持续通知实时显示剩余时间（每约 15s 更新），并带「暂停」「跳过」按钮；结束通知带「开始休息/专注」按钮，锁屏也能直接操作。
- **白名单保活引导（v1.6.0 新增）**：首次启动引导用户将 App 加入后台不限制/自启动白名单，规避国产 ROM 省电策略杀后台。

## 6. 每日打卡（习惯）

- 新建习惯，每日打卡。
- 近 7 天打卡格 + 连续天数 + 累计天数。

## 7. 倒数日 / 纪念日

- 新建倒数日，显示剩余天数。
- 支持「今天」「已过 N 天」状态。

## 8. 数据备份

- **导出 JSON**：全量数据（任务/记录/习惯/倒数日/设置），可导入恢复。
- **导出 CSV**：专注记录（日期、起止时间、任务、时长、类型），带 BOM，Excel 直接打开不乱码。
- **导入 JSON**：复用并集合并逻辑安全合并，不覆盖丢失。
- **记录备注（v1.6.0 新增）**：每条专注记录可添加备注，历史记录中显示并支持编辑。

## 9. 个性化

- **8 套主题**：tokyo、nord、dracula、catppuccin、gruvbox、rosepine、everforest、monokai。
- **强调色自定义**：12 个预设色点 + 取色器。
- **音效**：专注结束提示音（可开关）。

## 10. 沉浸专注模式

- 进入专注后全屏隐藏导航，防干扰。
- 浮动退出按钮 + Esc 键退出。

## 11. 结束鼓励语

- 每完成一个番茄（非跳过），随机弹出鼓励语（10 条库）。

## 跨平台支持

| 平台 | 形式 | 状态 |
|------|------|------|
| 网页 / PWA | `index.html` | ✅ |
| 安卓 | 原生 WebView 壳 APK | ✅ |
| Windows | Electron（NSIS + portable） | ✅ |

- **PC 端托盘 + 系统通知（v1.6.0 新增）**：Windows Electron 版支持最小化到系统托盘，专注/休息结束弹系统原生通知，点通知回到主界面。
